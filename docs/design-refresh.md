# ELEVATE デザイン調整

## 現在の実装

共通デザインはブランドの紫 `#4a0097`、白、チャコールを軸に、英字見出し・数字・余白・CTAを調整しています。
23ページ・6転送URL、セクション順、本文、フォーム仕様、リンク先は維持しています。
TOPのFVのみ、後続の明示的な指示に従い内部の装飾・レイアウトを変更しています。

## TOPのFV

ユーザーは https://www.propertyagent.co.jp/ の `top-kv js-top-kv` と同じ構図・線画・動きを希望し、色だけELEVATEの紫へ変更する方針を選択しました。

- 左コピー＋線画、中央コピー＋円弧、濃い紫の背景＋ブランド表示の3段階。
- スクロール区間は画面高（最大1200px）×4.5。参考の画面中央の通過位置に相当する境界で切り替え。
- 建物5秒、波7秒、シンボル6秒、波7秒の25秒周期。
- 建物・シンボルの線画形状は指定サイトの公開SVGから描画属性のみを抽出。イベント属性・スクリプト・外部参照は含めていません。
- 円弧は2本の半円と内円。16秒周期の回転と、各段階の表示・線の伸縮。
- 会社名・日本語・英字・CTA・リンク先はELEVATE。CTAは途中の段階でも利用可能。
- 参考サイトのCanvas/WebGLシェーダーやJSバンドルは移植せず、SVG＋CSSと既存のスクロール更新処理で実装しています。そのため、線の細かな揺らぎや描画は同一のレンダラーによる再現ではありません。
- FVの写真構図は廃止。画像ファイルや他セクションの写真には変更なし。
- reduced motion・JS無効・高さ650px未満では通常レイアウトで内容を表示。
- 装飾の一時停止ボタン、非表示タブ・画面外でのアニメーション停止。

## ソースの扱い

編集箇所は `content/pages/index.html`、`commn/css/site.css`、`commn/js/site.js`。
`python3 scripts/build-site.py` でTOPのHTMLへ反映しています。
公開ソースの解析用ダウンロードは `/tmp` に置き、参考サイトのJS・CSSバンドルは配信しません。

## 検証と限界

- `python3 scripts/verify-site.py`：全23ページ・6転送URL、内部リンク、アセット、アンカー、HTML構造、フォーム仕様。
- `node scripts/verify-interactions.cjs`：既存機能、表示モーション、FVの3段階と境界・逆スクロール・ヘッダー復帰・一時停止・画面外/タブ非表示・reduced motion・小画面・履歴復帰。
- `node --check commn/js/site.js`：構文確認。
- HTML差分はTOPとその本文ソースのみ。他ページ・URL・セクション順は変更なし。

Chromeの画面操作は自動承認レビューで拒否されたため、実ブラウザでの描画・PC/SPの目視比較は未実施です。
ピクセル単位の完全一致や、実画面でのモーションの一致は未確認です。フォームの実送信は行っていません。
