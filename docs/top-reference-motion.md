# TOP再現の対応表

参考：https://www.cosawell.co.jp/ （2026-09-17確認）
HTML、`assets/css/style.css`、`assets/css/base.css`、`assets/css/common.css`、`assets/js/common.js` の公開実装からレイアウト値とタイミングを確認。

| 参考先の動作 | ELEVATEでの実装 |
| --- | --- |
| 見出し文字が40ms刻み、行の開始が0/500/1000/1500ms | `top-effects.js`。文字自体は削除せず表示範囲を更新、キャレット付き |
| 英文は500ms、ロゴは1500ms、ライン・装飾は1800msで開始 | 同じ開始時刻。装飾のランダム文字を5秒ごとに再生 |
| 青/白/黄の斜線が流れる | CSSのグラデーション位置を連続更新 |
| メッセージの白帯・文字の左からの色変化 | IntersectionObserverと背景クリップ。写真は小幅にパララックス |
| 青い中心円・周囲のガラス調円・進捗線 | 既存の2事業に合わせた2項目のオービット。400ms回転、進捗線はスクロール連動 |
| PC/SPとも事業エリアを固定して切り替え | PCはセクション全体、SPは円形図部分をstickyに設定 |
| サービス写真の横スライド・ホバー時の幅拡張 | お仕事紹介の写真カードに適用。横スクロール・スクロールスナップ |
| 採用エリアの重ねカード | 社員インタビューにSwiper cardsを適用。回転-13度、オフセット10、600ms、4秒間隔 |
| 右端の縦書きセクションラベル | 現在のセクションに応じて更新。青い背景では白文字 |

文言はELEVATEの元のテキストを維持。参考先の4事業を創作して追加せず、既存の2事業へ動きを当てはめています。ヘッダーは過去のユーザー指定を維持し、hero退出後に表示します。写真は内蔵image_genで新規生成しています。

## 検証

- `python3 scripts/verify-top.py`：72の元テキスト断片、画像内本文、ローカルリンクと画像・ID
- `node scripts/verify-top-motion.cjs`：ヘッダー境界、PC/SPの事業切替、回転値、進捗値、戻りスクロール
- `node scripts/verify-top-effects.cjs`：開始時刻、文字保持、動きを減らす設定、ページ離脱
- `node scripts/verify-top-carousel.cjs`：cards設定、自動再生、ユーザー停止、画面外・別タブ・モーダル・減速設定

ブラウザ操作の許可がなく、実画面・実機での照合は未実施。検証はHTML・CSSの静的確認とJavaScriptのロジック検証です。ピクセル単位の一致を確認したものではありません。
